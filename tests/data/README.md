# テスト用の合成データ

ここにあるファイルは**すべて架空**です（会社名・法人番号・人名・Wikidata の ID は実在しません）。
取り込み器の形式とふるまいを確かめるためだけに、公開されている形式に合わせて作っています。

- `houjin_synthetic_v1.csv`, `houjin_synthetic_v2.csv`: 国税庁法人番号公表サイトの CSV（Unicode 版、ヘッダなし、30列）の形
- `wikidata_synthetic.json`: `kge.sources.wikidata.query()` の結果（SPARQL 1.1 Query Results JSON）の形
